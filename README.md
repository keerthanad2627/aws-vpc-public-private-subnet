# AWS VPC with Public and Private Subnets

## Project Overview
This project demonstrates how to build a secure AWS VPC with Public and Private Subnets.

## AWS Services Used
- Amazon VPC
- EC2
- Internet Gateway
- NAT Gateway
- Route Tables
- Security Groups
